# 따라큐 데스크톱 펫

전자칠판에서 손가락·전자펜으로 옮기고 함께 활동할 수 있는 Windows용 데스크톱 펫의 **배포 저장소**입니다. 이 프로젝트는 포켓몬 공식 제품이 아닌 비공식 개인 팬 프로젝트입니다.

## 설치

[최신 버전 다운로드](https://github.com/cantroxx/ai-ttarakyu/releases/latest)

1. 기존 따라큐가 실행 중이면 트레이 메뉴에서 **종료**합니다.
2. 릴리스에서 `MimikyuDesktopPet-Setup-버전-x64.exe`를 내려받아 실행합니다.
3. 설치 후 새 바탕화면 바로가기로 실행합니다. 기존 압축 폴더의 실행 파일은 옛 버전입니다.

ZIP은 설치 파일과 한국어 안내를 묶은 파일입니다. `latest.yml`과 `.blockmap`은 앱 자동 업데이트용이므로 직접 열 필요가 없습니다.

## 다음부터는 앱에서 업데이트

**펫 두 번 누르기 → 선생님 설정 → 업데이트하기**

새 버전 확인 → 다운로드 → 파일 확인 → 10초 후 설치·재실행으로 진행됩니다. ‘나중에 설치’를 눌러 미룰 수도 있습니다. 최신 버전이라면 별도로 다운로드하지 않습니다.

0.6.1부터 이 저장소 주소가 앱에 들어 있습니다. 0.6.0 이하에서는 이번 한 번 설치 파일로 업데이트하세요. 펫 위치·선택 화면·설정과 AI 연결 파일은 같은 Windows 사용자 계정에서 유지됩니다.

## 주요 기능

- 따라큐·메타몽·푸린 선택, 작은 터치 메뉴, 쓰다듬기·간식·공 놀이
- 전자칠판 화면 선택과 화면별 위치 저장
- 한국어 음성 대화와 데모 모드 (실제 AI 대화는 별도 API 설정 필요)

이 저장소에는 배포 파일과 안내를 올립니다. API 키·개인 설정·대화 기록은 포함하지 않습니다. Windows x64 설치본용이며 코드 서명 인증서는 적용하지 않은 개인용 빌드입니다. 학교 PC의 설치 정책에 따라 관리자의 확인이 필요할 수 있습니다.

실제 Windows 설치·재실행 및 전자칠판 터치 검증 범위는 각 릴리스 안내를 확인하세요. 포켓몬 및 캐릭터 관련 권리는 각 권리자에게 있습니다.
